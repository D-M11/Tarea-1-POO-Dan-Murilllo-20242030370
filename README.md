## Descripción del Proyecto
En este programa se manejan las clase Cuentabancaria,cuentacorriente,cuentaahorro
## Cuenta Bancaria 
manejada tos principales como el titular, saldo, numero de transaccione y número de cuenta.
## Cuenta Corriente 
gestiona el crédito y si se pasa ademas del pago de deudas
## Cuenta Ahorro
controla el retiro y comisiones de intereses además del rendimiento del dinero.

## Requisitos
tener NetBeans o cualquier compilador de java;
programa en documento src/cuenta bancaria
